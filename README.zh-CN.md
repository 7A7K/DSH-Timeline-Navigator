# DeepSeek Harness 时间线导航

一个面向 DeepSeek Harness Web UI 的可访问对话时间线插件，让长对话更容易浏览和定位，不修改 Harness 主程序。

## 功能

- 通过右侧边缘把手打开，也支持键盘聚焦和移动端点击。
- 按回合分组，自动标记当前聊天视口中的消息。
- 支持消息搜索和一键清空搜索。
- 即使旧消息尚未加载，也可以自动加载历史并跳转。
- 初次打开时默认合拢所有回合，先展示整体对话结构。
- 提供“展开全部 / 折叠全部”按钮，可一次管理所有回合。
- 按会话保存星标，每条消息右侧都有明确的星标按钮；触摸设备仍支持长按作为备用方式。
- 交互以直观点击为主：点击消息跳转，点击右侧星标收藏，按 `Escape` 关闭时间线。
- 记住启用状态、面板宽度、过滤模式、滚动模式和首次提示状态。
- 支持移动端底部面板，尊重系统减少动画设置。
- 使用 Harness 的 `ChatSnapshot` 和 `data-chat-anchor-key`，不扫描原始事件日志。

## 开发

```powershell
npm install
npm run check
npm run bundle
```

源码在 `src/`，`lib/` 是生成产物。不要直接修改 `lib/client.js`。

## 本地安装

```powershell
.\install.ps1 -Source (Get-Location).Path
```

安装后刷新 `http://127.0.0.1:3080/`。如果 Harness Web 进程仍使用旧 bundle，重启一次 Web 进程。

## 操作说明

| 操作 | 结果 |
| --- | --- |
| 悬停或聚焦右侧边缘 | 打开时间线 |
| 点击消息内容 | 跳转到对应消息 |
| 点击消息右侧星标 | 添加或取消星标 |
| 点击回合标题 | 展开或折叠该回合 |
| 展开全部 / 折叠全部 | 一次切换所有回合 |
| ↑ 按钮 | 跳到最早消息 |
| ↓ 按钮 | 跳到最新消息 |
| 移动端长按消息 | 作为收藏备用操作 |
| `Escape` | 关闭时间线 |
| 拖动面板左边缘 | 调整面板宽度 |
